Este es un proyecto de repaso para el segundo parcial de la materia de programación 2.

La función de este proyecto es poder calcular el costo de un viaje en taxi, la comisión de un vendedor y la multa por retraso en una biblioteca.

Se agregaron archivos como git ignore, un menú interactivo para seleccionar cada ejercicio que se quiera ejecutar, así como evidencias que respalden el funcionamiento del proyecto, y una bitácora para redactar dudas o problemas que se pudieran haber presentado.
